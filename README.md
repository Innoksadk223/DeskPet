# DeskPet — macOS 桌面桌宠（月薪猫 🐱）

桌面上一只会陪你聊天、帮你干活的 AI 小精灵。喊它一声「猫猫」就能对话，说「执行任务：…」它就在后台干活，干完用语音向你汇报。

> 🐱 本质：**依托 Hermes 0.19（`hermes-agent`）基础上套壳的 AI 语音助手**——Hermes 提供大脑（双 Agent 会话与工具），DeskPet 提供桌面形象、语音交互（唤醒/听写/TTS 播报）与桌宠体验。
> **Hermes 能做到什么，小助手也能做到什么**（联网搜索、终端操作、文件处理、浏览器等全工具）。

## 特性

- **宠物形象**：可来自 [petscodex.com](https://petscodex.com/) 等网站（下载 spritesheet 放入 `Pets/` 即可），也可以自己制作（`pet.json` + 序列帧图）
- **语音方案**：本地系统语音（免费离线）或豆包语音（火山引擎 Agent Plan，TTS 音色更自然）——在设置 ▸ 语音渠道 切换
- **对话能力**：接入 Hermes 双 Agent——聊天、派任务、联网查资料、操作终端/文件/浏览器
- **速度与思考**：响应速度与所配置模型一致；思考等级（reasoning_effort，high / medium / max）在 Hermes 侧调整（`~/.hermes/config.yaml`），调低思考等级可加快响应

> 📦 最新版本：[Releases](https://github.com/Innoksadk223/DeskPet/releases) 下载 `DeskPet-0.3.0.dmg`

## 一、安装（第一次用）

1. 下载 dmg → 双击打开
2. 把 **DeskPet.app** 拖进 **Applications**
3. 双击运行（如果提示"未验证的开发者"：**右键 → 打开** → 再点一次打开）
4. 首次运行会弹**麦克风/语音识别权限** → 点「允许」；误拒了去 系统设置 → 隐私与安全性 → 麦克风/语音识别 重新开启

> 需要本机已有 Hermes Agent 服务（桌宠的大脑）。从源码运行见[开发者文档](DeskPet/README.md)。

## 二、开始使用

### 和它说话（三种方式）

| 方式 | 操作 |
|---|---|
| **喊它** | 直接说「**猫猫**」（默认唤醒词）→ 它竖起耳朵听你说 |
| 打字 | 右键桌宠 →「**输入文字…**」 |
| 按住说话 | 右键 →「**语音输入**」（点击开始，说完再点结束） |
| 免唤醒 | 右键 →「**持续聆听**」勾选后不用喊词直接说话；说「**晚安**」退出 |

### 让它干活

| 你想做什么 | 这样说 |
|---|---|
| 普通聊天 | 「今天天气怎么样」「讲个笑话」 |
| 派任务 | 「**执行任务：**查一下明天天气」「帮我搜 Python 教程」 |
| 任务中途改需求 | 「跟任务说：改成红色」 |
| 取消/打断 | 「取消任务」「停一下」 |
| 重新开始对话 | 「新开对话」 |
| 查聊天记录 | 「聊天记录」 |
| 看帮助 | 「帮助」 |

任务干完会自动汇报（气泡 + 语音播报）。说人话就行，它能听懂。

### 常用设置

- **静音**：说「静音」或右键 →「静音播报」
- **唤醒词/灵敏度**：右键 → 设置 ▸ 唤醒词 / 唤醒灵敏度
- **声音**：右键 → 设置 ▸ 语音渠道（Edge / 豆包 / 系统，失败自动降级）
- **形象与性格**：右键 → 外观（7 个形象 + 人设，切换后下一条对话生效）

## 三、常见问题

| 问题 | 解决 |
|---|---|
| 没声音 | 检查是否静音（菜单「静音播报」）；设置 ▸ 语音渠道 换一个声线；豆包声线需在设置里配置 Key |
| 喊「猫猫」没反应 | 右键确认「唤醒词」是开启状态；灵敏度调到「灵敏」；检查麦克风权限 |
| 打开提示未验证 | 右键 → 打开（首次） |
| 桌宠不回答 | 确认本机 Hermes 服务正常；菜单栏点「重新连接助手服务」 |

## 四、架构概览

DeskPet 不是另一个独立的大模型，而是**在 Hermes 0.19（`hermes-agent`）之上做的桌面与语音外壳**。模型、联网搜索、终端、文件、浏览器等能力由 Hermes 提供；DeskPet 负责把这些能力变成可唤醒、可说话、可看见的桌宠助手。

### 1. 三层结构

| 层 | 负责什么 | 主要组件 |
|---|---|---|
| **语音层** | 唤醒、听写、静默分段、语音播报 | 本地 KWS、`SpeechInputController`、本地/豆包 ASR、Edge/豆包/系统 TTS |
| **AI Agent 层** | 会话、模型、工具、任务执行、协议解析 | Hermes serve、Hermes 主 Agent、任务 Agent、`HermesClient`、`HermesBridge` |
| **桌面交互层** | 宠物动画、气泡、右键菜单、设置与反馈 | `PetView`、`BubblePanel`、`StatusItemController`、`AppDelegate` |

`AppDelegate` 是三层之间的接线层，`HermesBridge` 是对话与任务协作的核心。

### 2. 一句话看懂工作流程

```text
你说「猫猫」
  → 本地唤醒检测
  → 听写（本地或豆包）
  → 指令路由 / Hermes 主 Agent
  → 普通问题直接回答，复杂操作派给任务 Agent
  → 结果通过 WebSocket 回到桌宠
  → 气泡显示正式内容，语音播报口语内容
```

### 3. 两个 Agent 怎么协作

- **主 Agent**：负责和你聊天、理解意图、决定是否派任务；它本身不直接操作工具。
- **任务 Agent**：在 Hermes 的常驻任务会话中执行搜索、终端、文件、浏览器等操作。
- 两者都依托同一个 Hermes serve，但使用独立会话；能力取决于 Hermes 当前配置的模型与工具。
- 一个任务执行时又来了新任务，桌宠会先排队，当前任务结束后按顺序执行，避免任务互相打断。
- 任务完成后，结果会回填主会话，由主 Agent 用更自然的口语向你汇报。

### 4. 双轨回复：为什么气泡和声音内容不同

Hermes 回复通常分成两条轨道：

```text
<spoken>适合直接听的口语总结</spoken>
<formal>适合在气泡中查看的完整内容</formal>
```

- **气泡**优先显示 `formal`，可以包含详细解释、代码和表格
- **语音**只播报 `spoken`，避免把代码和 Markdown 念出来
- 模型没有遵守格式时，DeskPet 会用完整回复兜底，不让回复消失

### 5. 语音链路与录屏兼容

- 唤醒：本地 sherpa KWS，不把唤醒音频上传到云端
- 听写：可选本地识别或豆包流式 ASR
- 播报：豆包 TTS → Edge TTS → macOS 系统语音，前一层失败自动降级
- VAD 会过滤纯静音和过短片段；播报时会暂停采集，避免桌宠听见自己的声音
- OBS/录屏切换音频设备或采样率时，桌宠会自动重建采集链路，并对多声道输入降混为单声道

### 6. 任务协议与服务自愈

主 Agent 与桌宠通过内部标记协作，普通用户不需要记这些标记：

| 标记 | 作用 |
|---|---|
| `<task>…</task>` | 派发任务 |
| `<task_steer>…</task_steer>` | 给执行中的任务追加要求 |
| `<task_status/>` | 查询当前任务与排队状态 |
| `<task_cancel/>` | 停止当前任务并清空等待中的任务 |

桌宠优先复用本机 Hermes serve；默认尝试 9119，被占用时自动使用 9120/9121。连接中断、服务重启或会话失效时，DeskPet 会自动重连、恢复会话，必要时重建会话。

运行数据与日志主要位于：

- 桌宠日志：`~/Library/Logs/DeskPet/deskpet.log`
- Hermes 日志：`~/.hermes/logs/agent.log`
- 配置与会话：`DeskPet/history/config/`、`DeskPet/history/data/` 或 macOS 的 `Application Support/DeskPet/`
