# MiMo 音色指南（小白版）

> MiMo 是小米出的云端语音服务。接上它以后，你的桌宠可以：
> 1. 用更好听的音色说话（还能**自己设计音色**、或**克隆你自己的声音**）；
> 2. 用它来听懂你说的话（语音识别）。
>
> 写给不懂技术的你——照着一步步做就行。豆包语音（火山引擎）的教程见另一份《豆包语音指南.md》。

---

## 零、5 分钟快速上手（从零到用上，照这个顺序做）

1. **申请 Key**：打开 **platform.xiaomimimo.com** → 注册登录 → 控制台「API Key 管理」→ 创建并复制 Key（详见「一、」）。
2. **填进 App**：右键桌宠 → 设置 ▸ 语音 ▸ **MiMo 语音设置…** → 粘贴 Key → 点「测试发声」，听到「你好，我是你的桌宠助手」就通了（详见「二、」）。
3. **选音色**：先用面板里的预置音色听几个；想自定义再进阶——
   - **文字设计音色**：配置文件里 `"mimoTTSMode": "design"` + `"mimoVoiceDesignPrompt": "沉稳的男声，像纪录片旁白"`（详见「三、玩法 2」）
   - **克隆音色**：安静环境录 10-20 秒 mp3，`"mimoTTSMode": "clone"` + `"mimoVoiceClonePath": "样本文件路径"`（详见「三、玩法 3」）
4. **切换播报**：设置 ▸ 语音 ▸ 播报方式 → **MiMo 语音**，之后新开一段对话生效（详见「四、」）。
5. **（可选）语音识别也用 MiMo**：设置 ▸ 语音 ▸ 识别 → **MiMo 识别**。注意它是整段识别——说完停 2 秒后上传，结果再等 1-3 秒（详见「五、」）。

卡在哪一步，就跳到对应章节看详细版；报错看「六、常见问题」。

## 一、什么是 MiMo？怎么申请 Key？

MiMo 语音目前**限时免费**（语音合成不花钱）。要用它，只需要一个「API Key」（可以理解成一张通行证）。

**申请步骤：**

1. 打开网址：**platform.xiaomimimo.com**（小米 MiMo 开放平台），注册一个账号。
2. 登录后，进入控制台，找到 **「API Key 管理」**。
3. 点「创建 API Key」，复制生成的那串字符（只显示一次，记得马上复制保存好）。

## 二、Key 填到哪里？

有两种方法，选一种就行。**推荐方法 1（App 里填，最简单）。**

### 方法 1：在桌宠 App 里填（推荐）

1. 右键点桌宠 → **设置 ▸ 语音 ▸ MiMo 语音设置…**
2. 把刚才复制的 Key 粘贴到「MiMo API Key」输入框里。
3. （可选）在下面选一个你喜欢的预置音色。
4. 点 **「测试发声」**——听到桌宠说「你好，我是你的桌宠助手」就说明 Key 填对了；点「保存」完成。

### 方法 2：直接改配置文件（高级）

配置文件的位置（用「文本编辑」或任意编辑器打开）：

```
DeskPet/history/config/deskpet-config.json
```

找到（或新增）这一行，把 Key 粘到引号里：

```json
"mimoApiKey": "把你的Key粘贴在这里",
```

保存文件，重启桌宠生效。

## 三、三种音色模式怎么用

MiMo 语音合成有三种玩法，由配置文件里的 `"mimoTTSMode"` 决定：

```json
"mimoTTSMode": "preset"
```

### 玩法 1：预置音色（preset，最简单）

小米已经做好了一批音色，直接选就行：

| 中文音色 | 英文音色 |
|---|---|
| 默认（mimo_default）、冰糖、茉莉、苏打、白桦 | Mia、Chloe、Milo、Dean |

**怎么切换：** 右键桌宠 → 设置 ▸ 语音 ▸ **MiMo 语音设置…** → 「预置音色」下拉框里选 → 保存。
（也可以改配置文件的 `"mimoVoice"`，比如 `"mimoVoice": "冰糖"`。）

### 玩法 2：设计音色（design）——用文字描述出你想要的声音

你可以用一句大白话描述想要的音色，MiMo 会现场「捏」出一个声音来。

**描述怎么写：** 说清楚性别/年龄感、音色质感、语速，可以加个比喻。例子：

- 「沉稳的男声，语速适中，像纪录片旁白」
- 「活泼的少女音，语速偏快，像游戏 NPC」
- 「温柔的年轻女声，轻轻的，像睡前故事」

**在哪填（配置文件两个键）：**

```json
"mimoTTSMode": "design",
"mimoVoiceDesignPrompt": "沉稳的男声，语速适中，像纪录片旁白",
```

保存重启后，右键桌宠 → 设置 ▸ 语音 ▸ MiMo 语音设置… → 测试发声，听听捏出来的声音。不满意就改描述再试。

### 玩法 3：克隆音色（clone）——用一段录音复制一个声音

想让孩子/家人/你自己的声音给桌宠配音？录一段样本交给 MiMo。

**怎么录样本：**

1. 找个**安静的环境**（关电视、关风扇，别有回声的房间最好）。
2. 用手机录音 App 或电脑的 QuickTime，**用正常音量说 10-20 秒**的话（比如念一段课文），中间别停顿太久。
3. 把录音**导出成 mp3 格式**，存到一个不会删的地方，比如：

```
~/DeskPet/mimo-sample.mp3
```

（`~` 就是你的用户主目录。想知道完整路径：在 Finder 里右键该文件，按住 Option，「拷贝为路径名称」。）

**路径填在哪（配置文件两个键）：**

```json
"mimoTTSMode": "clone",
"mimoVoiceClonePath": "/Users/你的用户名/DeskPet/mimo-sample.mp3",
```

保存重启 → 设置 ▸ 语音 ▸ MiMo 语音设置… → 测试发声。

## 四、怎么让桌宠用 MiMo 的声音说话（播报渠道切换）

Key 填好、音色选好后：

右键桌宠 → **设置 ▸ 语音 ▸ 播报方式** → 选 **「MiMo 语音」**。

之后桌宠所有语音播报（回复、任务结果、提醒）都用 MiMo 的声音。
想换回去：同一个地方选「系统语音」/「Edge 语音」/「豆包语音」就行。

## 五、怎么开启 MiMo 语音识别（听你说话）

**菜单路径：** 右键桌宠 → **设置 ▸ 语音 ▸ 识别** → 选 **「MiMo 识别」**。

**和豆包识别的行为差异（提前知道，不是坏了）：**

- MiMo 是「整段识别」：你**说完一句话停 2 秒**后，桌宠才把这段录音整体上传去识别，结果比豆包（边说边传）**多等 1-3 秒**才出来。属于正常现象。
- 长时间开「持续聆听」会一直录音上传，**比较耗额度**。参考价约 $0.074/小时（以官网价格页为准）。日常建议：手动语音输入或唤醒词模式用 MiMo 识别没问题；全天挂持续聆听的话，本地识别更省。
- 识别语言默认「自动」（中英文都能识别）；想固定语言，改配置文件 `"mimoASRLanguage"`：`"auto"` / `"zh"` / `"en"`。

**切回本地识别：** 同一个菜单选「本地识别」。

## 六、常见问题

| 现象 | 原因 | 解决 |
|---|---|---|
| 提示 **HTTP 401** / Key 无效 | Key 填错了或被删了 | 去 platform.xiaomimimo.com 重新确认 Key，重新粘贴保存 |
| 提示 **HTTP 429** / 限流 | 短时间请求太多 | 等一会儿再试；持续聆听开着会更容易触发 |
| 克隆音色不出声 | 样本文件路径错了/文件被移动了 | 检查 `mimoVoiceClonePath` 的路径和文件是否还在；重新拷贝正确路径 |
| 设计音色不出声 | 描述没填 | 检查 `mimoVoiceDesignPrompt` 不为空 |
| MiMo 语音突然不响了 | 网络问题或服务故障 | 桌宠会自动临时换回系统语音，不会哑；网络恢复后自动再用 MiMo |
| 想彻底删掉 MiMo | 不想用了 | 设置 ▸ 语音 ▸ 语音服务管理… → MiMo 语音 → 删除（会清掉 Key 和相关配置） |

## 附：本指南对应的配置键速查

| 键 | 作用 | 默认 |
|---|---|---|
| `mimoApiKey` | API Key（空 = 不启用） | 空 |
| `mimoBaseURL` | 自定义服务地址（一般不用填） | 空（用官方） |
| `mimoTTSMode` | 音色模式：preset / design / clone | preset |
| `mimoVoice` | 预置音色名 | 茉莉 |
| `mimoVoiceDesignPrompt` | 设计音色的文字描述 | 空 |
| `mimoVoiceClonePath` | 克隆样本 mp3 的绝对路径 | 空 |
| `mimoStyleInstruction` | 朗读风格（如「语气轻快一些」，可选） | 空 |
| `mimoASRLanguage` | 识别语言：auto / zh / en | auto |
