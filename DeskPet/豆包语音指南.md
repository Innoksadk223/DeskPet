# 豆包语音指南（小白版）

> 豆包语音是火山引擎（字节跳动）的云端语音服务。接上它以后，你的桌宠可以：
> 1. 用豆包的音色说话（比系统语音自然，声线可选）；
> 2. 用「豆包识别」听懂你说的话——**流式识别**（边说边传），出字比整段识别快。
>
> 写给不懂技术的你——照着一步步做就行。MiMo（小米）语音的教程见另一份《MiMo音色指南.md》。

---

## 零、5 分钟快速上手（从零到用上，照这个顺序做）

1. **申请 Key**：火山引擎官网注册 → 控制台创建 API Key（`ark-` 开头），详见「一、」。
2. **填进 App**：右键桌宠 → 设置 ▸ 语音 ▸ **豆包语音设置…** → 粘贴 Key → 点「测试发声」，听到说话就通了（详见「二、」）。
3. **挑声线**：设置 ▸ 语音 ▸ **豆包声线** 里选（Vivi、晓荷、灿灿、咪仔、云舟等 8 个；也能自定义，详见「三、」）。
4. **切换播报**：设置 ▸ 语音 ▸ **播报方式** → **豆包语音**（详见「四、」）。
5. **（可选）语音识别也用豆包**：设置 ▸ 语音 ▸ **识别** → **豆包识别**——流式边说边识别，说完约 2 秒出字（详见「五、」）。

卡在哪一步，就跳到对应章节看详细版；报错看「六、常见问题」。

---

## 一、什么是豆包语音？怎么申请 Key？

豆包语音按用量/套餐计费（App 内提示「持续聆听会消耗时长额度」，即火山引擎的 Agent Plan 类套餐）。要用它，需要一个「API Key」（通行证，`ark-` 开头）。

**申请步骤：**

1. 打开火山引擎官网 **volcengine.com**，注册账号（一般要实名认证）。
2. 进入控制台，找到**语音技术 / 大模型语音（Ark）**相关服务并开通。
3. 在 **API Key 管理** 里创建一个 API Key——`ark-` 开头的那串字符，复制保存好（只显示一次）。

**截图位：**（控制台页面截图，待补——火山控制台改版较频繁，找不到入口就搜「API Key」）

> 提示：如果买的是 Agent Plan 套餐，Key 和端点以套餐页面给出的为准；App 里识别端点留空会用默认 plan 端点。

## 二、Key 填到哪里？

**推荐直接在 App 里填：**

1. 右键桌宠 → **设置 ▸ 语音 ▸ 豆包语音设置…**
2. 面板有两组四个框：
   - **语音合成（TTS）**：Base URL（**留空用默认**）+ API Key（粘贴 `ark-` 开头的 Key）
   - **语音识别（ASR）**：识别端点（**留空用默认**）+ 识别 Key（**留空 = 复用上面的语音 Key**，一般不用单独填）
3. 点 **「测试发声」** 听一下；确认没问题点「保存」。

**高级：直接改配置文件**（`DeskPet/history/config/deskpet-config.json`）：

```json
"duoyunApiKey": "ark-你的Key",
"asrApiKey": "",
```

识别端点相关键：`asrURL`（留空默认）/ `duoyunBaseURL`（留空默认）。保存后重启桌宠生效。

## 三、声线怎么选（含自定义）

**菜单路径：** 右键桌宠 → 设置 ▸ 语音 ▸ **豆包声线**（需先配好 Key，否则这一项是灰的）。

App 内置的声线：

| 女声 | 男声 |
|---|---|
| Vivi（中英混合）、晓荷（温柔甜美）、灿灿、咪仔（活泼俏皮） | 云舟（稳重大气）、涛程（阳光）、柳飞、大义（成熟稳重） |

选完立即生效（下次播报就是新声音）。

**自定义声线（高级）：** 菜单最底下「**自定义声线…（高级）**」——输入豆包官方的 `voice_type` 编号（以火山引擎官方声线表为准，形如 `zh_female_xxx_bigtts`），适合官方上了新声音但 App 还没收录的情况。

配置文件对应键：

```json
"duoyunVoiceType": "zh_female_vv_uranus_bigtts",
"duoyunResourceId": "seed-tts-2.0"
```

（`duoyunResourceId` 一般不用动，除非火山侧换了资源 ID。）

## 四、怎么让桌宠用豆包的声音说话（播报渠道切换）

右键桌宠 → **设置 ▸ 语音 ▸ 播报方式** → 选 **「豆包语音」**。

> 注意：只选声线 ≠ 日常播报走豆包（三个语音服务选一个生效）。选完声线记得来这里切「豆包语音」，切换提示里也会提醒你。

想换回去：同一个地方选「系统语音」/「Edge 语音」/「MiMo 语音」。豆包临时失败时桌宠会自动降级到系统语音，不会哑。

## 五、怎么开启豆包语音识别（听你说话）

**菜单路径：** 右键桌宠 → **设置 ▸ 语音 ▸ 识别** → 选 **「豆包识别」**。

**行为特点（和本地/MiMo 的差别）：**

- **流式识别**：边说边传，说完约 2 秒出字——比 MiMo 整段识别（多等 1-3 秒）**更快**，长句也不怕。
- 持续聆听开着会一直消耗**时长额度**（按套餐计费）；全天挂聆听建议用本地识别省额度。
- 识别失败时，本次会话自动回退本地识别（会弹提示），不用你操作。

**切回：** 同一个菜单选「本地识别」或「MiMo 识别」。

## 六、常见问题

| 现象 | 原因 | 解决 |
|---|---|---|
| 提示 **401 / Key 无效** | Key 填错/被删 | 去火山控制台重新确认 Key（`ark-` 开头），重新粘贴保存 |
| 提示 **429 / 限流** | 短时间请求太多 | 等一会儿再试；持续聆听更容易触发 |
| 提示 **55000000 resource mismatched** | 资源 ID / 端点和 Key 的套餐不匹配 | 检查 `duoyunResourceId`/`duoyunBaseURL` 是否被人改过；不知道怎么改就清空恢复默认 |
| 豆包声线菜单是灰的 | 还没配 Key | 先做「二、」配好 Key |
| 选了声线但声音没变 | 播报方式没切到豆包 | 设置 ▸ 语音 ▸ 播报方式 → 豆包语音 |
| 自定义声线没声音 | voice_type 编号不对 | 核对火山官方声线表；或先换回内置声线 |
| 套餐过期后识别报错 | plan 端点失效 | 豆包语音设置里把「识别端点」换成新服务的完整 `wss://` 地址（或续费后留空用默认） |

## 附：本指南对应的配置键速查

| 键 | 作用 | 默认 |
|---|---|---|
| `duoyunApiKey` | 语音合成 API Key（空 = 不启用） | 空 |
| `duoyunBaseURL` | 合成端点（留空用默认 plan 端点） | 空 |
| `duoyunResourceId` | 资源 ID（一般不动） | seed-tts-2.0 |
| `duoyunVoiceType` | 声线编号（内置 8 个可菜单选） | Vivi |
| `asrURL` | 识别端点（留空用默认；换服务填 wss://） | 空 |
| `asrApiKey` | 识别 Key（空 = 复用 duoyunApiKey） | 空 |
