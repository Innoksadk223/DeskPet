# 桌宠使用手册

> 版本：2026-08-16 · 适合第一次用桌宠的你——照着做就行

## 1. 这是什么

桌面上的一只小精灵（默认月薪猫 🐱，共 7 个形象）。它会：

- **陪你聊天**：直接对它说话或打字，背后是 AI 助手（Hermes 主 Agent）
- **帮你干活**：说「执行任务：…」它就在后台派 AI（任务 Agent）去执行——查资料、写脚本、整理文件都可以，干完向你口语汇报
- **听你喊它**：喊「嘿猫猫」它就竖起耳朵听你说（不用点鼠标）
- **开口说话**：回复会用语音播报（Edge/豆包/系统三种声音可选）

## 2. 启动

- **日常**：双击项目里的「启动桌宠.command」（会自动构建并启动）
- **或**：终端 `cd ~/Downloads/项目-助手/DeskPet && ./build-app.sh && open DeskPet.app`

**第一次启动**：系统会弹「麦克风/语音识别」权限询问 → 点「允许」。误拒了去 系统设置 → 隐私与安全性 → 麦克风/语音识别 重新开启。

## 3. 怎么和它交流

| 方式 | 操作 |
|------|------|
| 打字 | 右键桌宠 →「输入文字…」 |
| 按住说话 | 右键 →「语音输入」（点击开始，说完再点结束） |
| **喊它** | 直接说「嘿猫猫」（默认唤醒词）→ 它开始听你说话 |
| **免唤醒** | 右键 →「持续聆听」勾选后，不用喊词直接说话；说「晚安」退出聆听（退出词可改） |
| 打断任务 | 说「打断任务」/「停一下」——只停后台任务，聊天照常 |
| 停止回答 | 说「停止回答」——只停当前回复，任务照常跑 |
| 全部停止 | 说「全部停止」——主回复和任务一起停 |
| 静音 | 说「静音」或右键 →「静音播报」 |

## 4. 让它干活（任务）

| 你想做什么 | 这样说 |
|-----------|--------|
| 普通聊天 | 直接说：「今天天气怎么样」 |
| 派任务 | 「执行任务：查一下明天天气」「帮我搜 Python 教程」 |
| 任务中途改需求 | 「跟任务说：改成红色」/ 直接说「改成…」 |
| 取消任务 | 「取消任务」/「打断任务」（只停任务，聊天照常） |
| 停止回答 | 「停止回答」——只停主 Agent 当前回复，不影响任务 |
| 全部停止 | 「全部停止」——主回复与任务一起停，两侧各自收口 |
| 重新开始对话 | 「新开对话」 |
| 查聊天记录 | 「聊天记录」 |
| 删任务记录 | 「删除任务：列目录」（先确认） |
| 清空对话历史 | 「删除对话历史」或右键 →「清理对话历史」（先确认） |
| 看帮助 | 「帮助」 |

任务干完会自动汇报结果（气泡 + 语音）。派任务的触发词共 36 条，记不住没关系——直接说人话，它也能听懂。

## 5. 右键菜单分区

右键点桌宠，菜单从上到下：

| 分区 | 内容 | 干什么用 |
|------|------|---------|
| 状态行 | 状态：空闲/… | 看它现在在干嘛（置顶灰字） |
| **对话** | 输入文字…、语音输入 | 和它说话 |
| **会话** | 中断任务、开始新对话 | 控制当前对话/任务 |
| **历史** | 清理对话历史、历史对话 ▸ | 管理历史记录（查看/删除） |
| **偏好** | 静音播报、唤醒词开关、开机自启、持续聆听、宠物大小 ▸ | 常用开关 |
| **设置** | 设置 ▸、切换状态 ▸ | 全部设置入口 / 手动切动画状态 |
| **系统** | 使用帮助、关于 DeskPet、退出桌宠 | 帮助 / 版本信息 / 退出 |

菜单栏点爪子图标 🐾 也有同样的菜单（分区风格一致，少几项会话区操作）

## 6. 设置说明（设置 ▸）

| 菜单项 | 说明 |
|--------|------|
| 设置唤醒词… | 喊什么词唤醒它（默认「嘿猫猫」） |
| 唤醒灵敏度 | 灵敏 0.15 / 标准 0.25 / 迟钝 0.4（越灵敏越易误触发） |
| 退出词… | 持续聆听时说哪些词退出——**多个词用逗号分隔**，如「晚安，再见」 |
| 豆包语音设置… | 豆包 TTS：API Key（火山引擎）+ Base URL；识别端点/识别 Key（见下） |
| 豆包音色… | 豆包 TTS 音色（默认 Vivi/uranus；可自定义 voice_type） |
| Edge 音色… | Edge 语音音色（默认晓晓，9 个实测可用；选择即试听） |
| 听写识别 | 本地识别（离线）/ 豆包识别（云端更准，省时省力但花时长额度） |
| 形象 | 切换外观（7 个：月薪猫/卡皮巴拉/月薪喵/JokeBear/Momonga/Phoebibi/ddo-zvzo） |
| 人设 | 切换性格（2 个：月薪猫/卖萌小可爱；新开对话生效）；含「直接编辑人设文件…」「高级：直接编辑语音提示词文件…」 |
| 语音播报方式 | 选当前说话的声音：Edge / 系统 / 豆包（单选，选中的就是现在的声音） |
| 系统声线… | macOS 系统语音音色（需先到系统设置下载中文声线） |
| 语音服务管理… | 查看/删除语音服务清单 |
| 恢复默认设置… | 一键重置全部设置 |

**豆包语音设置弹窗（4 格）**：上方「语音合成」Base URL + Key（Key 必填）；下方「语音识别」识别端点 + 识别 Key。留空 = 用默认（豆包 plan 端点 / 复用语音 Key）——**套餐过期或换服务时填新的 wss:// URL 即可**。

**省钱提示**：豆包识别带静音跳过（VAD）——不说话的时间段不会上传，只按实际说话时长计费。

## 7. 常见问题

| 现象 | 怎么办 |
|------|--------|
| 喊它没反应 | 确认已授权麦克风；日志里应有「唤醒监听已启动」（`~/Library/Logs/DeskPet/deskpet.log`） |
| 说话识别成乱码 | 豆包识别更准（设置 ▸ 听写识别 ▸ 豆包识别）；口音重可试本地识别 |
| 豆包不发声/识别失败 | 检查设置 ▸ 豆包语音设置里 Key 是否有效；失败会自动降级（气泡有 ⚠️ 提示） |
| 回复没声音 | 设置 ▸ 语音播报方式检查当前选择；Edge 需要 Hermes venv 装了 edge-tts |
| 连不上助手 | 右键 ▸ 设置 ▸ 重新连接助手服务；服务重启中会有提示，好了自动恢复 |
| 双击启动没反应 | 看「启动桌宠.command」窗口报错；桌宠已在运行时新实例会被拒绝（正常防双开） |
| 想让它开机自动出现 | 右键 ▸「开机自启」勾选 |
| 设置的词/音色重启后丢了 | 配置在 `history/config/deskpet-config.json`；「恢复默认设置」会重置全部 |

## 8. 数据与隐私

- 你的对话、任务、转录都存在本机项目 `history/` 下（`config/` 是配置，`data/` 是数据）
- 清理对话历史、转录过期清理**只动 data/，绝不碰配置**
- 豆包 Key 只存在你本机 `history/config/deskpet-config.json`
- 打包分发的 DeskPet.app / DeskPet.dmg 会自动剥离所有 key——发给别人也不会泄露
